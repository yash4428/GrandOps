# Translations for Yash to review

All Hindi and Punjabi strings in `messages/hi.json` and `messages/pa.json` were written by an AI assistant during the initial build and need a native-speaker check. Priority keys (most visible):

- `today.*` (dose cards, "Dose taken" button, missed/upcoming labels)
- `report.*` ("Something's wrong" flow, reasons, thank-you message)
- `medicineNames.*`, `instructions.*`, `colours.*`
- `missionControl.stage.*` (shown in the demo video)

Check especially: plural forms in `today.doseCount`, the tone of `today.confirmed`, and `missionControl.stage.govern` (Hindi "शासन", Punjabi "ਪ੍ਰਬੰਧ").

Added for Mission Control: `missionControl.mergeRequest` (मर्ज अनुरोध / ਮਰਜ ਬੇਨਤੀ).
